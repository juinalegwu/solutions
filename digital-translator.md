### TIER 1: THE LITERAL ASSISTANT

**Task: Explain how to make breakfast to a computer.**

First of all, get all the required ingredients and equipment.

1. Go to the kitchen.
2. Get the bread, eggs, butter, salt, and other required ingredients.
3. Put a frying pan on the cooker.
4. Add a little butter or oil to the pan.
5. Break the eggs into a bowl.
6. Add a little salt and mix.
7. Pour the eggs into the frying pan.
8. Cook until ready.
9. Toast the bread.
10. Put the cooked eggs and bread on a plate.
11. Serve the breakfast.

**Assumptions:**

- The ingredients are available.
- The cooker is working.
- The person knows how to use the kitchen equipment.
- There is electricity or another working cooking source.
- The person has the necessary cooking utensils.

A computer needs clear and specific instructions because it cannot guess what we mean.

### TIER 2: THE ATM ALGORITHM

**Task: Explain how an ATM dispenses money.**

An algorithm is a step-by-step set of instructions used to solve a problem.

**ATM algorithm:**

1. Insert the ATM card.
2. Enter the PIN.
3. The ATM checks whether the PIN is correct.
4. If the PIN is incorrect, display an error message.
5. If the PIN is correct, display the available options.
6. Select the withdrawal option.
7. Enter the amount to withdraw.
8. The ATM checks whether the account has enough money.
9. If the balance is insufficient, display an error message.
10. If the balance is sufficient, subtract the withdrawal amount from the account.
11. Dispense the cash.
12. Display the remaining balance.
13. Return the ATM card.

**What happens when something goes wrong?**

The ATM should display an error message when the PIN is incorrect, the balance is insufficient, or there is a problem dispensing cash.

**Difference between a problem, an algorithm, and a program:**

- Problem: The user wants to withdraw money.
- Algorithm: The step-by-step instructions for withdrawing money.
- Program: The actual computer code that makes the ATM follow those instructions.

### TIER 3: THE CALCULATOR

**Task: Explain how a calculator works.**

A calculator receives numbers and an operation from the user, processes them, and displays the answer.

**Input:**
- First number: 10
- Second number: 5
- Operation: Addition (+)

**Processing:**

The calculator follows the instruction to add the two numbers.

10 + 5 = 15

**Output:**

15

**What happens when dividing by zero?**

A calculator should not perform division by zero because it is mathematically undefined. Instead, it should display an error message.

**The three main stages:**

1. Input: The numbers and operation entered by the user.
2. Processing: The calculator performs the requested calculation.
3. Output: The calculator displays the result.

### TIER 4: THE DATA TRANSLATOR

**Task: Represent customer information digitally.**

Customer information:

- Name: Victor
- Age: 30
- Balance: 150000.50
- Active: Yes

**Data representation:**

| Information | Value | Data Type |
|---|---|---|
| Name | Victor | String/Text |
| Age | 30 | Integer |
| Balance | 150000.50 | Float/Decimal |
| Active | Yes | Boolean |

**Why does a computer need data types?**

Data types help a computer understand how to store and process different kinds of information.

For example:
- A name is stored as text.
- An age is stored as a whole number.
- A balance can contain decimal numbers.
- An active status can be represented as True or False.

**How does a computer represent information?**

A computer represents information using binary digits: 0 and 1.

Text, numbers, and other information are converted into digital representations that the computer can store and process.

### TIER 5: THE ONLINE STORE

**Task: Explain how an online store processes an order.**

An online store receives information from a customer, processes it using instructions, stores the information, and produces an output.

**1. Input**

The customer provides information such as:
- Customer name
- Product name
- Quantity
- Price
- Delivery address
- Payment information

**2. Instructions**

The program follows exact code commands and rules in a particular order.

For example, it follows step-by-step rules to:
- Check whether the product is available.
- Calculate the total price.
- Verify payment.
- Confirm the order.

**3. Processing**

The program uses the information provided to perform calculations and check the order.

For example, if a customer buys two cakes at ₦5,000 each:

2 × ₦5,000 = ₦10,000

**4. Storage**

The system stores the order information so it can remember purchases, process deliveries, track inventory, and keep payment records as proof.

**5. Output**

The system produces results such as:
- An order confirmation.
- A receipt.
- A payment confirmation.
- An updated inventory record.

### FINAL CHALLENGE: EXPLAIN THE WHOLE SYSTEM

An algorithm is the plan, while a program is the implementation.

An algorithm is the step-by-step instructions we design to solve a problem. A program is those instructions written in a programming language so that a computer can execute them.

For example, when using an ATM to withdraw ₦10,000:

1. Insert the ATM card.
2. Enter the PIN.
3. The ATM verifies the PIN.
4. It checks whether the account has at least ₦10,000.
5. It subtracts ₦10,000 from the account.
6. It dispenses the money.

The algorithm is the paper blueprint showing the steps. The program is those rules written in code and installed in the ATM to make it work.

### FINAL REFLECTION

A computer cannot see, touch, or experience physical things, so it uses digital symbols like numbers and text to stand in for real-world objects and follows strict rules to process them.

It only manipulates data according to step-by-step instructions.

For example, when someone buys two cakes at ₦5,000 each, the computer does not physically see the cakes. Instead, it receives digital information such as:

- Address: Text
- Product: Cake
- Quantity: 2
- Price: 5000

It processes the information by multiplying 2 × 5000 = ₦10,000, checks the payment, and subtracts two cakes from the inventory.

This shows that a computer works with digital representations of real-world information and follows instructions to produce results.
